# API WARS Montería

App del equipo para la hackatón API WARS: cobra con Factus Pay y, al quedar pagado, factura con Factus v2.

```bash
npm install
npm run dev
```

Abre la dirección que muestra Vite. Sin credenciales funciona con mocks.

- [AGENTS.md](AGENTS.md): reglas y datos de las APIs. Dáselo a tu agente.
- [docs/simulacro.md](docs/simulacro.md): plan del simulacro.
